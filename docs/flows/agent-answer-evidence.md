# Agent 的运行范围、证据引用与回看

页面保存当前会话的 KnowledgeBase 选择。发送前，后端先校验会话归属，再解析启用目录并冻结本次范围；新会话默认所有启用库，旧会话迁移保留 news。SSE 的 `run_started` 将会话 ID、运行 ID 和实际范围交给页面。运行期间保存的新选择只影响下一次提问。

主模型接收当前问题、保留的历史问题和本次 Tool 结果；旧答案、旧 Tool 和摘要仍可在近期回看中展示，但不能进入新运行充当证据。`search_documents` 可按用户要求缩小范围，`read_document` 同时核验允许范围和知识库启用状态；已知 Document ID 不能越界。资料不足时不能自动扩大页面选择。

工具与普通检索、全文共用已采用版本的可见性规则：新候选准备期间旧版本仍可用，拒绝或删除后停止后续取用。管理页保留的历史和原件不通过 Agent 工具开放。

Tool 返回实际读到的片段及应用分配的引用标识，证据关系随消息写入 checkpoint。模型引用这些标识作答。结束时，服务端从持久状态得到最终答案、完成状态、有效与无效引用，作为 Done 返回；前端校正临时 token，并同步最新保留的问答。回放使用同一套关联规则，工具调用仅在所属问答内配对。

用户点击行内引用或引用列表，阅读器显示当时取得的片段，再单独请求当前全文。原文变化时同时保留旧依据和新内容；删除、停用、服务不可用分别提示。无法从索引文本可靠映射到 Markdown 原文时不猜测高亮。原始 Cosine score 只表示检索相似度。

| 失败或生命周期边界 | 用户看到 |
| --- | --- |
| 目录加载失败、空选或目标失效 | 提问前失败，不退化为无过滤搜索 |
| Tool 试图越界 | 明确失败，不能凭已知 ID 绕过范围 |
| 模型生成未知或旧运行引用 | 引用无法核验提示，不提供伪造阅读入口 |
| 上游重试产生临时文字 | Done 用已保存答案校正，回看与终态一致 |
| 达到模型预算、上游截断或流中断 | 明确标记未完成，已有内容不冒充完整答案 |
| 结束后历史同步失败 | 保留本次页面内容并提供同步重试 |
| 较早问答被压缩 | 当前页和刷新后均只保留近期原始问答；摘要标作背景 |

压缩只在新提问开始时执行，保留完整近期问答，不切断正在使用的证据链。退出可回看状态不等于旧 checkpoint 已物理清除，也不提供独立完整档案。设计取舍见 [ADR 0021](../adr/0021-agent-run-evidence-and-replay.md)；跨层验证见 `backend/tests/test_agent_evidence_scope.py` 和 `frontend/src/pages/AgentChatPage.spec.ts`。
