**要交付什么：** 中间件内部发起的模型调用（历史摘要压缩）也进账本。它本来就走同一个被包住的模型实例，这条工单的价值是把这个事实证明下来——被漏掉的恰是长会话里最烧钱的那部分。做完能演示的事：把会话跑到触发摘要压缩，账本里出现那次摘要调用的记录。
