# 03: 明细接口——只能查到自己的记录

**要交付什么：** 当前账号的用量明细只读接口，分页返回，支持时间范围与模型两个可选筛选。做完能演示的事：登录后翻自己的调用明细，换一个账号看不到别人的记录。

**被谁阻塞：** 02

**状态：** 待开工

- [ ] 明细接口返回当前账号的记录：用另一个账号写入的记录在同一次请求里查不到。
- [ ] 翻页不重不漏：写入已知条数的记录后逐页取完，取到的调用标识集合恰好等于写入的集合。
- [ ] 响应形状是「记录数组 + 是否还有下一页」，不带精确总数。
- [ ] 时间范围筛选按传入的 UTC 起止时刻生效，边界是闭开区间；模型筛选只返回该模型的记录；两个筛选可以同时使用。
- [ ] 没有任何记录时返回空数组与「没有下一页」，而不是错误。
- [ ] 同一次运行里落在同一毫秒的多条记录，跨页时既不会重复出现也不会被跳过。
