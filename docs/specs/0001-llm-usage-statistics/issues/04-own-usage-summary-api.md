# 04: 汇总接口——与明细同口径

**要交付什么：** 当前账号的用量汇总只读接口，返回同一筛选条件下的输入、输出、缓存、合计四个 token 各自的总和与调用次数。做完能演示的事：任意调一组筛选条件，汇总的四个数字逐列等于明细逐条相加。

**被谁阻塞：** 03

**状态：** 待开工

- [ ] 明细支持的每一个筛选维度，汇总接口都接受；同一个筛选条件下，汇总的四个 token 合计与调用次数逐列等于明细里全部记录的对应值之和。
- [ ] 缓存那列只累加上游报了缓存的行，缺缓存的行不当作 0 参与累加。
- [ ] 没有任何记录时，汇总返回四个 0 与次数 0，而不是错误。
- [ ] 汇总不受分页影响：明细分多页时，汇总仍等于全部记录之和。
