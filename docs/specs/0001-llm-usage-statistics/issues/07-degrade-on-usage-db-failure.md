# 07: 用量库故障不影响对话

**要交付什么：** 写入改成进程内队列加批量落库；用量库连不上时降级、只记日志；队列满或写入持续失败也留下日志；进程关停时尽力把队列刷完。做完能演示的事：把用量库指到不可达的地址，对话照常跑完，日志里有记录；恢复之后新记录继续落库。

**被谁阻塞：** 02

**状态：** 待开工

- [ ] 用量库不可达时，问一次 Agent 仍然拿到完整回答，采集入口不向调用方抛异常、不把它拖慢到可观察的程度。
- [ ] 上述情形在日志里留下一条记录，能看出是用量库的问题而不是对话的问题。

- [ ] 队列为空时刷写不做任何数据库访问。
