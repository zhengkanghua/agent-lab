# 01: 运行脱离连接：关掉页面后这次运行继续跑完

**要交付什么：** 客户端在流中途断开（关掉页面、断网、切走会话）之后，这次运行继续跑到结束、并把结果写进会话；下次打开会话读到完整答案。今天断开会把运行取消，checkpoint 里只剩一条提问。顺带改正事件流收尾那句与实际不符的注释——它把断连描述成正常关闭，实际走的是取消。

**被谁阻塞：** 无（可立刻开工）

**状态：** 待开工

- [ ] 客户端在收到首帧之后断开连接，稍后回放这个会话能读到完整答案（现在是：只剩提问）
- [ ] 完全没有订阅者时这次运行也能跑完并把结果写进会话（现在是：没有人在拉，运行停在原地）
- [ ] 断开之后运行正常收尾，同一会话的下一次提问在历史里能看到上一轮的答案（现在是：上一轮没有答案）
