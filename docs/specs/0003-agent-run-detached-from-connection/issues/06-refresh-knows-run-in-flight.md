**要交付什么：** 刷新页面时如果上一轮还在跑，界面明确显示「正在生成」、发送键不可用，并自动等到它结束再换成最终内容——不会出现「界面说没有回答、服务端说还在生成」这种自相矛盾的状态。

**状态：** 待开工

- [ ] 刷新后若最后一轮没有回答、而会话有在途运行，界面显示「正在生成」并禁用发送（现在是：显示「这一轮没有留下回答」）
- [ ] 服务端不再报有在途运行之后，界面自动换成最终内容（现在是：没有轮询）
