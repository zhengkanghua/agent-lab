# 04: 停止按钮真的能停住

**要交付什么：** 用户点停止后，服务端在很短的时间内停下这次运行、此后不再产生新的模型调用，已经输出的内容按截断留在会话里；重复点停止不报错；带的是上一轮的运行 id 时不会误停当前这一轮。前端点停止改为调用新接口，并保持连接直到服务端给出终态，于是「点停止时看到的」与「刷新后看到的」是同一套。

**被谁阻塞：** 01、02、03

**状态：** 待开工

- [ ] 在途时调用停止接口，这次运行以终态结束，并且此后不再出现新的模型调用（现在是：接口不存在）
- [ ] 停止之后回放能读到停止前已经输出的内容（现在是：接口不存在）
- [ ] 重复调用停止接口幂等成功（现在是：接口不存在）
- [ ] 在途运行的 id 与请求里的运行 id 不相等时，停止请求不影响当前这一次运行（现在是：接口不存在）
- [ ] 前端点停止后显示的内容与状态，与刷新之后看到的一致（现在是：点停止靠断开连接，刷新后是另一种标签）
