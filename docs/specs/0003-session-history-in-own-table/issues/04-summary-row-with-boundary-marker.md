## 两处判断（已审定）

1. **摘要行的 `seq` 放在所属那组的最前面**（我拍的）：压缩发生在那轮提问之时、模型从那轮起只剩摘要，而读方只按 `seq` 排序，所以它应当紧跟在上一轮之后、本组提问之前——「按序排序」与「按组归类」因此保持一致。已写进注释。
2. **字段取不到的摘要不落表**（子代理报上来的取舍，我判可行）：那两个字段可能为 `None`（不经过运行上下文的路径），而「属于哪一次运行」这一列对不上就写不进去——**不编占位**与既有「运行标识缺失的组宁可跳过、不编 id」同一口径。
