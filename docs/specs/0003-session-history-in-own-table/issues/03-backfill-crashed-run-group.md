**要交付什么：** 进程被强杀、OOM、断电那一次运行没有任何收尾代码会执行，它不会自己落表。下一次进入这个会话、任何一次运行的收尾，都会把它补进表里。写入方只补缺的那些组，已经落表的一字不改。
