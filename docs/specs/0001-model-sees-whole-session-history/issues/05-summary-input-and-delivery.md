## 一条我请子代理回答而不是自己拍的取舍（它没有自行加保护，只记了边界）

**「不截断」在「摘要模型窗口小于主模型」的配置下会把请求撑爆。** spec 把「摘要模型窗口不小于主模型」写成前提，而本项目的模型窗口是管理员逐条填的、主模型与摘要模型是**不同条目**。子代理的处理是：在构造处注释里写明这个前提、指出**今天由装配方保证**（`agent/runtime.py` 的压缩直接用主模型、不另建客户端），并明说「**代码没有哪一处拦着以后传一个窗口更小的客户端进来**」；**没有自行加保护**（符合我 brief 里的要求）。

这条我判为「已知前提 + 今日不可达」：装配处唯一传值的地方就是主模型，所以当下不会发生；将来若真要让摘要换一个更小的模型，那是**另一个决策**，得同时给出「被折掉那段放不下」时的做法。已登记在此，**不引入现在没人会踩到的校验**。
