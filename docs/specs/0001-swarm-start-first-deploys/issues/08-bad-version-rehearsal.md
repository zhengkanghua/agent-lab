# 08: 验收：坏版本不接班（演练 4a、4b）

**要交付什么：** 两种坏法各测一次，看的是同一件事——好版本会不会被坏版本替掉。4a：新版本启动期就失败（容器退出），期望旧任务不被停、更新自己回滚、用户无感。4b：新版本起来了但就绪检查一直不过（进程不退），记录旧任务是否被停、以及那个不健康的新任务是否在收流量。这一条同时是停手线的落点。
