# ADR 0015: 语义检索页视觉重构

## 上下文 (Context)
当前的 `SearchPage` 将结果展示为带有厚重外边框的卡片，这使得阅读体验产生碎片感，不像是一个连续的“研究流”。顶部的输入框也静态固定在顶部，在没有任何搜索记录时缺乏视觉焦点。

## 决策 (Decision)
我们将在不改变底层数据流逻辑的前提下，为语义检索页引入“文档流 (Document Stream) / 时间线 (Timeline)”的视觉架构：
1. **输入坞过渡 (Center-to-Top Transition)**：`SearchComposer` 在初始状态（无检索记录）下将居中显示，占据视觉焦点。当开始检索后，它会平滑过渡并吸附到页面顶部。
2. **垂直时间线 (Vertical Timeline)**：在 `SearchRecordTurn` 左侧引入一条贯穿的垂直线，将用户的每次检索作为时间线上的一个节点，从而将零散的查询串联成一次连贯的研究。
3. **无界排版 (Borderless Typography)**：`SearchResultCard` 将移除目前的 `surface-raised` 背景色和明确的外边框。我们将依靠留白、文字层级和极弱的底部内凹线来区分不同的“知识片段”。

## 后果 (Consequences)
* 界面将变得更加连贯流畅，提供类似聊天流或研究日志的体验。
* CSS 将被大量重构，用边距 (margin/padding) 和排版代替显式的边框和背景色。
* 需要小心处理左侧时间线在不同状态（加载中、错误、折叠）下的渲染连贯性。
