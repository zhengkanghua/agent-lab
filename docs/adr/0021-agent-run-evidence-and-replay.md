# Agent 证据隔离到每次运行，终态与回看共用 checkpoint

2026-09-08，第二阶段允许同一会话切换 KnowledgeBase 范围。若继续把旧答案、Tool 内容或事实摘要送给主模型，切到 B 后仍可能用只属于 A 的事实作答；因此每次运行冻结实际范围，主模型只接收保留的历史问题和当前运行消息，知识库事实必须重新取得。会话范围独立保存在归属表，运行中的改选留给下一次。

引用标识由应用为实际 Tool 结果分配，随同一条消息的 artifact 保存归属、content_hash 和片段。流式收尾与历史回放共用证据核验，只承认本次运行、允许范围内的成功结果；程序确认出处身份，不把它解释为模型结论已获事实认证。

临时 token 可能来自上游重试，不能直接作为持久答案。Done 从 checkpoint 取得最终文字、完成状态和引用，前端据此校正并同步近期记录；预算耗尽、上游截断和未持久化的中断不伪装为完整回答。

沿用现有压缩机制，在新提问开始时压缩，并向前保留完整近期问答。早期问答和引用不再提供逐条回看；摘要可展示为背景，但不送给主模型充当证据。代价是后续提问可能需要重新检索，依赖很早的问答时也可能需要用户补充上下文。没有增加独立会话档案、完整文档历史或逐 token 存储。

打开引用读取 PostgreSQL 当前全文，同时展示当时片段；原文变化、删除和停用明确提示。content_hash 不能提供历史版本，也不保证 Markdown 索引片段能定位到原始语法中的字符位置，所以无法可靠定位时不高亮。

本决策扩展 [ADR 0020](0020-knowledge-base-management-slice.md) 的范围规则，保留 [ADR 0002](0002-frontend-detects-stale-body-by-comparing-hashes.md) 的正文对比、[ADR 0003](0003-agent-v1-is-read-only.md) 的 Tool 只读和 [ADR 0004](0004-checkpointer-tables-outside-alembic.md) 的存储生命周期；压缩不承诺物理销毁旧 checkpoint。
