# 字号与字重收敛为令牌阶，不再各处写裸值

全站字号令牌化为 `--fs-` 前缀的 7 档，字重收敛为 `--fw-normal / semibold / bold` 三档，12px 成为字号硬下限；档位定义与用途见 `tokens.css`。改动前全站字号声明几乎不引令牌，实测最小值不到 10px，中文在 12px 以下笔画互相糊在一起，那不是「小一号」，是不可读；字重散落十几个不同值。字号前缀不沿用 `--text-*`，是因为那同时是文字颜色的命名空间，读代码时分不出来。

字重定三档而不是按观感实测出的两档，有实测依据：Windows 中文环境实际落到微软雅黑，它只提供 Regular 与 Bold 两个字面，560 及以上的所有声明值渲染结果完全相同；macOS 的 SF Pro 与 Windows 的 Segoe UI 提供独立的 Semibold。三档记的是「意图」，砍成两档会丢掉 `semibold` 与 `bold` 在代码里本来有意义的语义区分，也牺牲了那些平台上的逐档效果。曾试过自造一个 13px 中间档，它与所有主流规范不一致，且与 12px 的观感差异小到不足以支撑一档，已删。

## Consequences

在 Windows 上 `--fw-semibold` 与 `--fw-bold` 看起来一样，想靠字重区分两个层级时要挑别的办法（字号、颜色、留白）。全站只豁免三处裸值：`SafeMarkdown.vue` 里相对父级缩放的行内代码与不承载中文的引用上标，以及 `style.css` 里作为 rem 基准的 `body` 字号。
