# 会话历史落业务表，checkpointer 只管上下文记录

用户回看的会话历史（见 [0043](0043-session-history-outlives-summary.md)）改由业务表承载：每轮结束把这一轮写进我们自己的表，界面从此读它；LangGraph 的 checkpointer 退回它本来的角色，只存上下文记录，压缩策略怎么改都与用户看到的东西无关。

**为什么**：两件事的生命周期不同。会话历史要能被查询、能跟账号一起被清理、能在换压缩策略时纹丝不动；而 checkpointer 的结构归上游所有（[0004](0004-checkpointer-tables-outside-alembic.md)），它每次压缩都会破坏性地重写状态，这正是 0043 的由来。把用户的记录挂在它上面，等于把「用户能查到什么」交给上游的实现细节。分开之后，写入点落在我们自己的运行收尾路径上（那里已有事务、错误处理与测试），读取路径变成一次普通查询。

**代价**：这是仓库里第一次为同一段对话保留两份数据。[replay.py](../../backend/src/agent_lab/agent/replay.py) 的模块说明当初明确拒绝过这种做法（「副本注定和真实上下文分叉」），它依据的前提是「界面 = 模型所见」，0043 已把这个前提撤销。剩下要守的是：两份数据不一致时，界面必须说清哪一份是模型的记忆。

## Considered Options

**压缩发生时把被移除的原文归档进业务表。** 归档范围恰好等于「模型忘掉的部分」，但写入点落在压缩中间件内部——那是个今天零数据库依赖的纯逻辑模块，要在里面引入连接、事务与失败重试；而且归档与 checkpoint 写入跨两个连接池，无法用一个事务覆盖，失败时会重复归档或丢一段。

**不删状态，只在模型调用前裁剪。** 单份数据、零副本，代价是 checkpoint 无界增长：上游每走一步都把消息全量写一份，今天靠「只留最近 20~40 条」把这个量压住，一旦不再压缩，长会话的存储与读取成本按轮数平方级上升。

## Consequences

会话历史的写入点在运行收尾路径上，而一次运行可能被排空、被别的进程接手、被用户停止（见 [0035](0035-run-outlives-its-subscriber.md) 与 [0040](0040-run-handover-on-deploy.md)），所以这一行必须按运行去重：同一次收尾被执行两次，不能写成两轮。写进去的也不能只有正常完成那一种：用户按停止、上游失败或超时、排空后放弃，各自产出不同终态的轮次，都要落进这张表。

**这张表存的是整轮完整结构，不是问答文本。** 工具调用与工具返回的正文、引用证据（文档归属、`content_hash`、来源）、范围快照、完成状态和运行标识都要在里面——界面上的工具轨迹与引用今天是拿 checkpoint 里的消息现算的（`replay.py` 的轨迹配对与 `resolve_citations` 都依赖 `ToolMessage` 及其 `artifact`），一旦压缩删掉那些消息，只存问答就意味着一轮的痕迹与引用永久消失。代价是这张表会大：一轮的工具正文可以到 6KB。

（引用证据里不再带正文片段——那一段已经由本表的工具正文承载，不需要副本；这是 [0045](0045-model-sees-whole-session-history.md) 那次改动一起定的，两份 ADR 与对应的 spec 口径一致。）

**保留策略不跟 checkpoint 走**：用户不删就永久保留。checkpoint 有被清理的既定出口——用户删会话时的 `adelete_thread`，以及 `agent-lab prune-old-threads` 这个手工运维命令（默认只预演，`--yes` 才真删）——这张表不能跟着那些出口走。

**删除路径因此有多个出口要接**：用户删会话，以及两个运维清理命令（`prune-old-threads` 与 `prune-orphan-threads`；后者面对的那批行的来源是「删一个正在运行的会话时等它停下的上限到了、删除继续执行，而那次运行随后仍会把收尾内容写回」——这条路径**在升级之后会反复产生**，不是历史存量）。删旧会话那条的删除顺序今天写的是「先 checkpointer、后业务行，留下的是可自愈的残余」，多一张表就要重新论证这个顺序还成不成立。

**摘要那条分界痕迹要一并转存过来。** [0045](0045-model-sees-whole-session-history.md) 把「压缩发生在哪一轮之前」记在 checkpoint 的摘要消息上（那时界面还没有本表可读），本表落地时要把它带过来，否则界面上画不出那条分界线。
